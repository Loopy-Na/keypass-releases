# 키패스 APK 배포

키패스의 APK와 앱 업데이트 정보를 공개하는 저장소입니다. 앱 소스는 별도 비공개 저장소에서 관리합니다.

[최신 버전과 APK 다운로드](https://github.com/Loopy-Na/keypass-releases/releases/latest)

## 설치

1. 릴리스에서 `keypass-버전.apk`를 다운로드합니다.
2. 기존 키패스를 삭제하지 않고 APK를 열어 업데이트합니다. Android에서 다운로드한 앱의 설치 확인이나 Play Protect 검사를 요청할 수 있습니다.
3. 앱 하단 또는 설정의 **업데이트 내역 → 업데이트 설치 허용**에서 키패스의 앱 설치를 허용합니다.
4. **자동 업데이트**를 켜 두면 충전 중·요금 없는 Wi-Fi·휴대폰 유휴 상태에서 Android가 하루 주기로 확인합니다. 설치 확인이 필요한 경우 알림 또는 **설치 계속** 버튼을 사용합니다.

Android 17(API 37) 이상용입니다. 앱이 실행되는 기기의 정책에 따라 자동 설치가 제한될 수 있습니다.

## 배포 파일

- `keypass-버전.apk`: 설치 파일
- `update.json`: 버전, 설치 주소, SHA-256, 변경 내역
- `SHA256SUMS.txt`: APK 검증값

앱은 새 APK의 패키지·버전·서명·검증값을 확인합니다. 계정, 출입 기록, 서명키와 앱 소스는 이 저장소에 올리지 않습니다.

비공식 개인용 앱입니다. 기존 서비스나 아파트 관리 주체가 제공하거나 보증하는 앱이 아닙니다. 본인에게 사용 권한이 있는 계정과 현관에서만 사용하세요.
